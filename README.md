## Overview

Built an end-to-end Power BI dashboard to analyze retail sales performance across Products, Customers, and Geographic Regions.

The solution uses PostgreSQL, SQL, Power Query, DAX, and a Star Schema data model to transform raw transactional data into actionable business insights.


## Tools & Technologies

* Power BI
* PostgreSQL (pgAdmin4)
* SQL
* Power Query
* DAX
* Star Schema Data Modeling


## Dashboard Highlights

### Executive Summary

* Revenue, Orders & Profit YTD vs LY
* Revenue Trend Analysis
* Category & Segment Performance

### Product Analysis

* Revenue by Subcategory
* Profit Contribution Analysis
* YoY Growth Analysis

### Customer Analysis

* Customer KPIs
* Repeat Customer %
* Active Customer Trend
* Segment Profitability

### Geographic Analysis

* Revenue Distribution by State
* Profit by Region
* Regional Profit Margin Analysis


## Data Model

Star Schema consisting of:

* Sales Fact
*  Customer Dimension
* Product Dimension
* Date Dimension
* Location Dimension
* Shipping Dimension

## Project Outcome

Developed an interactive analytics solution that enables stakeholders to monitor business performance, evaluate profitability, analyze customer behavior, and identify growth opportunities across products and regions.
